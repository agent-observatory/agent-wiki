# L4 조회 평가

합성 자료의 기대 후보를 먼저 고정한 10문항과, 운영 조회에서 관찰한 실패를 재현하는 회귀 사례 4개다. `npx tsx experiments/query/evaluate.ts`로 같은 자료에 기존 가중치 순위와 필드별 BM25를 적용한다. DB·모델 호출은 없다.

| 정책 | 문항 통과 | 평균 Recall@3 |
| --- | ---: | ---: |
| 기존 필드 가중치 | 10/10 | 1.0 |
| BM25 필드 조합 | 10/10 | 1.0 |

현재 작은 평가셋에서는 동률이다. BM25 개선 효과를 입증하지 않았으며 긴 문서·유사 주제·한국어 표현 차이를 실제 실패 사례에서 추가한다. 알고리즘 변경보다 근거 연결과 조회 범위가 정확한지 먼저 확인한다. fixtures.json의 `question`은 사람 질문이고 `query`는 미리 정한 검색어다. 에이전트의 질문 변환 능력을 이 검사로 평가하지 않는다.

`tests/query.test.ts`는 별도 CI DB에서 현재/이력·범위·미확인·관계 방향·원문 위치·trace·격리·한도·정제 불변을 검증한다. 운영 원문을 테스트 자료에 복사하지 않는다. 최종 답변의 인용 정확성·필요한 근거의 누락·L5 토큰은 향후 에이전트 실행 평가 대상이다.

운영 조회는 성공 메타데이터만 retrieval_events에 30일 저장한다. 상세 조회된 근거를 실제 인용한 것으로 간주하지 않는다. 실패 이벤트는 같은 traceId로 OCI 로그에 남는다. 쿼리 해시·참조 ID·반환 문자 수·지연으로 반복 조회를 조사하며 모델 입력/출력 토큰은 호스트가 보고하지 않으면 미확인이다.

기존 `experiments/retrieval/cases.json`의 회귀 검사에서 순수 필드 BM25는 한 단어가 제목에 있는 참고 문서를 복수 검색어가 있는 결정문보다 높게 반환했다. 검색어 포함 범위 우선 + 필드 BM25로 보완하고 기존 7개 비의미 검색 사례의 1순위를 별도 순수 검사로 고정했다. `limit_%` 같은 문자 그대로의 설정 이름도 보존한다.

## 운영에서 관찰한 회귀 사례

2026-09-14 운영 Workspace의 `query search`(current)에서 관찰한 잘못된 후보를 합성 유사 자료로 옮겼다. 운영 원문·Claim 본문은 저장소에 넣지 않으며 `regressionDocuments`는 제목 패턴만 흉내 낸 짧은 문장이다. 각 사례는 `corpus`로 보이는 문서를 고정하고, 기준은 Recall@3보다 엄격한 `empty`(후보가 없어야 함) 또는 `top1`(핵심 문서가 1위)이다. `knownFailing`은 작성 시점의 결과이며 `tests/query-ranking.test.ts`가 그대로인지 검사한다. 순위를 바꾸면 이 값을 의도적으로 뒤집어야 한다.

| 사례 | 관찰 | 현재 결과 | unmatchedTerms |
| --- | --- | --- | --- |
| r01 `K3s 전환 이유` | K3s 지식이 없는데 "전환·이유"가 있는 유료 계정·Container Instances·다크 테마 문서가 `found`를 채움 | 실패 | `k3s` |
| r02 `출력 상한 max_completion_tokens` | 스타일 가이드가 "출력·상한"으로 1위 | 실패 | `max_completion_tokens` |
| r03 `Wiki Page Claim 분리` | "분리"와 부분 문자열 `wiki`(agent-wiki)만 맞음 | 실패 | `page`, `claim` |
| r04 `K3s 전환 이유` + K3s 문서 있음 | 포함 범위 우선 규칙 때문에 흔한 두 단어 문서가 희귀한 한 단어 문서보다 앞섬. Recall@3는 통과 | 실패(top1) | 없음 |

r01~r03의 공통 원인은 질문의 핵심 대상이 지식에 없을 때 일반 단어만 맞는 후보가 `status=found`로 반환되는 것이다. 순위 알고리즘을 바꾸는 대신 `unmatchedTerms`를 응답에 추가해 L5가 "핵심 단어는 어디에도 없다"를 읽을 수 있게 했다. r04는 `dde32b8`에서 한국어 회귀를 막기 위해 넣은 포함 범위 우선 규칙의 반대 급부다. 희귀 단어를 IDF로 가중한 포함 범위가 후보 해법이지만 기존 회귀 사례와 함께 비교한 뒤 결정한다.
