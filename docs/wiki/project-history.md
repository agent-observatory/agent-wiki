# 프로젝트 역사

프로젝트 역사와 결정 이유는 **원격 Wiki의 지식**으로 관리한다. 이 파일에 내용을 중복 작성하지 않는다.

- [Atlas → Observatory → 독립 Wiki](https://agent-wiki.duckdns.org/workspaces/e9094745-057e-4e99-91f4-033931966042/knowledge/415c538b-4fa4-406e-9dd2-2f8033f13629)
- [Agent Wiki · 여기서 이어서 시작](https://agent-wiki.duckdns.org/workspaces/e9094745-057e-4e99-91f4-033931966042/knowledge/a84e7ee1-b586-4871-89f7-9d96b495d40f)

소유자 로그인이 필요하다. 원문은 불변 보관하고, 정제 기록과 지식 개정은 실제 반영 시점에 추가한다. 문서 설계 변경이 원격 지식에 자동 반영되지는 않는다. 위 지식의 최신성은 각 개정·근거·확인 시점을 따른다.
