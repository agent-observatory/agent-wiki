# 프로젝트 역사

프로젝트 역사와 결정 이유는 **원격 Wiki의 L3 지식**으로 관리한다. 로컬 파일에 역사 본문을 중복 작성하지 않는다.

[Agent Wiki](https://agent-wiki.duckdns.org)의 개인 작업 Workspace에서 확인한다. 개발 데이터 초기화로 삭제된 지식 링크는 유지하지 않는다. 수집한 L1이 있다는 사실만으로 프로젝트 역사가 정제·반영됐다고 보지 않는다.

원문은 불변 보관하고 정제 실행·지식 Version은 실제 반영 때 추가한다. 로컬 설계 문서 수정이 원격 지식으로 자동 반영되지는 않는다. 현재 반영 여부는 [운영 현황](../OPERATIONS.md)을 따른다.
